隐私说明

最后更新 · 2026 年 11 月 12 日 · 仅适用于本网站

这一页说明你访问这个网站时会发生什么。它故意写得很短，因为站点本身做得很少：一组静态的 HTML、CSS 与 JavaScript，没有后端、没有账号、没有统计。

一句话：本站不会自动收集任何信息。唯一离开你浏览器的内容，是你在申请内测时主动写进公开 GitHub issue 的那些文字。

本站不做什么

  • 没有 Cookie、没有 localStorage、不做浏览器指纹。
  • 没有统计脚本、没有会话录制、没有广告像素。
  • 不引用第三方字体、图标 CDN 或外部脚本。打开开发者工具的网络面板，只会看到本站域名下的请求。
  • 没有注册表单：这一页没有任何一个输入框会把你的邮箱发到我们控制的服务器。

托管日志

本站托管在 GitHub Pages。和任何网站托管方一样，GitHub 会处理标准请求数据（IP、User-Agent、请求路径）用于投递页面与防护服务。这部分处理适用 GitHub 隐私声明，不由我们控制，我们也拿不到这些日志。

内测申请

申请内测会在本项目的 GitHub 仓库里开一条公开 issue，也就是说：

  • 你的 GitHub 用户名和你写下的全部内容对任何人可见，也会被搜索引擎收录。
  • 内容由 GitHub 按其条款存储；删除账号或删除该 issue 即可从公开视野中移除。
  • 我们只问项目类型、使用的 Coding Agent、以及你最想守住的行为。请不要贴源码、密钥、客户数据或任何你不愿意公开的内容。

模型 Key 与源码

产品的设计前提是：模型 API Key 与源码留在你自己的机器上。本网站不会索取其中任何一个。如果未来版本提供「把证据上传给同事评审」，那会是按项目显式开启的选项，而不是默认行为。

关于儿童、追踪与画像

这是一个开发者工具，不面向儿童；这里也没有可画像的东西：没有账号、没有行为数据、没有第三方标签。

疑问与删除

在仓库里开一条 issue——内测申请也在同一个地方。如果你已经发过想删掉的内容，在那条 thread 里说一声即可删除。

本说明的变更

如果本站以后增加了真正的账号体系、统计或托管后端，这一页会在功能上线之前更新，顶部的日期也会随之改变。

本说明描述的是当前行为，不是法律合同。它刻意写成「可核对」的样子：上面每一条都可以用浏览器的网络面板和公开仓库自行验证。
