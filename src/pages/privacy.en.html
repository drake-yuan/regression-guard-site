Privacy

LAST UPDATED · 12 NOVEMBER 2026 · APPLIES TO THIS WEBSITE

This page describes what happens when you visit this website. It is deliberately short, because the site does very little: it is a static set of HTML, CSS and JavaScript files with no backend, no accounts and no analytics.

In one sentence: this site does not collect anything automatically. The only information that leaves your browser is what you choose to type into a public GitHub issue when you request early access.

What this site does not do

  • No cookies, no local storage, no fingerprinting.
  • No analytics, no session recording, no advertising pixels.
  • No third-party fonts, icon CDNs or script tags. Open the network panel and you will only see requests to this domain.
  • No sign-up form: there is no field on this site that sends your email address to a server we control.

Hosting logs

The site is served by GitHub Pages. Like any web host, GitHub processes standard request data (IP address, user agent, requested path) to deliver the page and to protect the service. That processing is governed by GitHub's privacy statement, not by us, and we do not receive those logs.

Early access requests

Requesting early access opens a public issue in the project's GitHub repository. That means:

  • Your GitHub username and everything you write are visible to anyone, and are indexed by search engines.
  • GitHub stores it under its own terms; deleting your account or the issue removes it from public view.
  • We ask only for project type, coding agent and the behavior you want protected. Please do not paste source code, credentials, customer data or anything you would not publish.

Model keys and source code

This website never asks for an API key or source code. The current engine makes zero model calls, so there is no key to hand over; if a bring-your-own-key option is added later, it stays on your machine. If a future version offers to upload evidence so a teammate can review it, that will be an explicit, per-project opt-in — not a default.

Children, tracking, profiling

This is a developer tool. It is not directed at children, and there is nothing here to profile: no account, no behavioural data, no third-party tags.

Questions or removal

Open an issue in the repository — the same place the early access requests live. If you have already posted something you want removed, say so in that thread and it will be deleted.

Changes to this note

If the site later adds a real account system, analytics or a hosted backend, this page will be updated before that change ships, and the date at the top will change with it.

This note describes current behaviour, not a legal contract. It is written to be checkable: every claim above can be verified with the browser's network panel and the public repository.
